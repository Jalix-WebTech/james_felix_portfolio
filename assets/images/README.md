# Image assets guide

Add only genuine, owned or appropriately licensed images here. Do not use invented certificate scans, testimonials, awards or project screenshots.

| Folder | Recommended content | Suggested format |
|---|---|---|
| `profile/` | Your professional portrait and optional social preview image | WebP/JPG; portrait 4:5, social preview 1200×630 |
| `certificates/` | Original certificate images | PNG/JPG/WebP; preserve original aspect ratio, ideally 1600px+ wide |
| `projects/` | Genuine screenshots of your own projects | WebP/PNG; consistent 16:10 crop |
| `testimonials/` | Portraits supplied with permission | WebP/JPG; square crop |
| `recognition/` | Genuine award or recognition images | PNG/WebP/JPG |
| `logos/` | Institution and technology logos where local assets are licensed | SVG/PNG |

Use relative paths such as `assets/images/profile/james-felix.webp` in `js/config.js` or the relevant data file. Optimise images before adding them; avoid huge originals.
